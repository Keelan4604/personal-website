Privacy Policy

Last updated 22 September 2026

This policy covers keelan-mail-mcp, a personal software tool written and operated by Keelan O'Doherty for his own use.

What it accesses

The tool uses Google's Gmail API to read messages and create drafts in mail accounts owned by Keelan O'Doherty, after he grants access through Google's standard OAuth consent screen.

What it stores

Message data is processed on Keelan O'Doherty's own computer and is not transmitted to any third party, server or analytics service. Authentication tokens are stored locally on that computer.

Who can use it

The tool has a single user, its author. It is not offered to the public and collects no data from anyone else.

Sharing

No data is sold, shared or disclosed to third parties.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions, which invalidates the stored tokens.
